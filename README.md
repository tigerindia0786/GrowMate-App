# GrowMate — Android app starter

This is an Expo / React Native starter for an Android creator-discovery app.

## Run it
1. Install Node.js (LTS) on a computer.
2. Install Expo tooling: `npm install`
3. Start: `npx expo start`
4. Install Expo Go on an Android phone and scan the QR code.

## Current demo features
- Mobile-first GrowMate interface
- Demo sign-in screen (not real authentication)
- Creator discovery feed with sample content
- Add creator profiles for YouTube, Instagram, and Facebook
- Submit YouTube videos, Instagram Reels/posts, and Facebook videos/posts for discovery
- Profile and admin overview placeholder

## Before public release
This starter is not a production-ready service and does not yet include a live backend, database, secure authentication, moderation service, payment processing, or a signed APK. Connect a backend (for example, Firebase or Supabase), implement server-side admin roles, validate YouTube URLs, add privacy/terms pages, and test on real devices.

**Policy-safe design:** GrowMate is for genuine content discovery. Do not award points, money, or benefits for subscribing, watching, liking, or commenting. Do not require users to exchange engagement. YouTube prohibits artificial engagement and incentivized metric manipulation.
